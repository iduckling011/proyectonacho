# App de Notas

Proyecto final de una aplicación web multiplataforma para gestionar notas. Cuenta con internacionalización (inglés y español) y un flujo de despliegue automatizado.

## Tecnologías utilizadas
- Ionic y Angular
- Node.js
- GitHub Actions para integración continua
- GitHub Pages para el despliegue

## Para correr el proyecto localmente
1. Clonar este repositorio.
2. Abrir la terminal en la carpeta del proyecto y ejecutar `npm install` para las dependencias.
3. Ejecutar el comando `ionic serve` para levantar el servidor de pruebas.

El proyecto ya está publicado y funciona automáticamente desde GitHub Pages.
